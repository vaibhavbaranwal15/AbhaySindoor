# Abhaya Sindoor Website

A responsive product website for **Abhaya Sindoor**, built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.
3. Internet is only needed for Google Fonts and WhatsApp links; the core layout works locally.

## Change the images
Replace these files in the `images/` folder, keeping the exact filenames:
- `abhaya-logo.svg` — brand logo
- `abhaya-hero.svg` — hero/about illustration
- `sindoor-15gm.svg` — 15gm pack image
- `sindoor-30gm.svg` — 30gm pack image

The product cards also have a **Change image** button. It previews a chosen image in the current browser session only. To publish a permanent change, replace the matching image file in `images/`.

## Before publishing
The included SVG product pictures are editable placeholder illustrations, not photographs of the actual product. Replace them with accurate photos of your real packaging before publishing. Only use product claims (such as “organic”, “safe”, or “scalp protection”) if they are substantiated and accurate.
